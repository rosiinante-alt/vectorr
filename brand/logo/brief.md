# Vectroy — Logo Brief

**Name:** Vectroy (formerly Vectorr). Spoken VEK-troy; built from "vector" + "troy" (the old Vectorr tail kept as a mark of continuity).
**What it does:** AI vectorization and vector-art optimisation. Upload PNG/JPG/WEBP → clean SVG/DXF/EPS/PDF/G-code/DST; background removal; trace-and-simplify; output ready for Cricut, laser cutters, embroidery, print.
**Audience:** crafters and Cricut owners, laser-cut hobbyists and small shops, independent designers, print shops. Practical, price-aware, visually literate.
**Tone:** plain-spoken, dry-witted but warm ("Your files stay yours."), confident, no hype-speak, precision-minded.

## Adjectives → visual cues
1. **Crisp** → exact geometry, hard edges, true corners, one line that lands.
2. **True** → the vector is the truth; the raster is the guess. Fidelity, faithful trace.
3. **Precise** → grid-locked, equal angles, controlled curve count.
4. **Clean** → few elements, generous negative space, no ornaments.
5. **Practical** → works on a cutter bed, a favicon, a shop sign; no preciousness.

## Constraints
- Must work in the existing UI: header at 24 px, single accent colour `#0072CC`, light-mode app, Inter typeface.
- Must work one-colour, reversed on dark, embroidered/ cut (DST/DXF — thin details die).
- Category sits in: software tool + maker/craft. Both audiences must feel it's for them.

## Competitors / shelf
Vector Magic, Illustrator (Ai), Inkscape, Recraft, Vectorizer.ai, Vectosolve, SVGOMG, Cricut Design Space.
Category typography: abstract square logos, blue tech gradients, lightning bolts, "magic" sparkles, pen-nib + node combos.

## Clichés to avoid unless freshly formed
- Bézier "pen tool" anchors + handles (every vector tool has it).
- Lightning bolt, sparkle/star, upward arrow, cursor, puzzle piece.
- Ribbon/loop infinity for "simplify", swirl for "transform".
- Generic slab initial in a rounded square.

## Word map
| Axis | Nouns | Metaphors | Opposite (what we are NOT) |
|---|---|---|---|
| Crisp | edge, corner, node, path, line | "cut, don't smear" | blur, jaggies, gradient mush |
| True | atlas, blueprint, proof, mirror, trace | "the trace that tells the truth" | guess, drift, approximation |
| Craft | laser bed, blade, mat, cut sheet, spool | "curves that cut" | dashboard, enterprise, cloud |
| Math | arc, angle, grid, constant | "straight lines and one good curve" | noise |
| Name | V, tr → y | "V with a trace" | — |

**Intersections circled:** *edge/cut* + *V* + *true trace* — a V whose diagonal is a cut edge with a second, clean edge beside it: the jagged pixel line and the clean vector line in the same stroke.

## Candidate mark types
1. **Letterform** — V built from a raster step and a vector edge.
2. **Monogram / negative space** — V as the vertex of two traces.
3. **Abstract** — a path with a knife-cut join.
4. **Wordmark-led** — Vectroy with a modified `V`.
5. **Combination** — symbol + wordmark (final default).
